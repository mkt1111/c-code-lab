# C# Code Lab

An interactive study guide for C# and .NET concepts, organized into categorized lessons with code examples and quizzes.

## Features

- Lessons grouped by category (core concepts, OOP principles, data structures, async programming, modern patterns, performance, and more) with C# code samples
- Per-lesson quizzes plus a general quiz page
- Lesson progress tracking stored in the browser's localStorage
- Sidebar navigation and previous/next lesson buttons

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- React Router
- TanStack Query
- lucide-react
- Vitest

## Running locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```
